Workflow Detail

Writing Module — Step by Step

Choose Mode

User selects Practice or Validate

Practice: AI generates a CAE-style prompt for essays, letters, reports, or reviews. Validate: User pastes their own writing to get scored.

Generate Task

AI creates an exam-style prompt

GPT-4o-mini generates a realistic CAE prompt with context, instructions, and target word count. User sees it exactly as they would in the real exam.

API: POST /api/writing/generate-task — temperature 0.8 for creative variety
Write & Auto-Save

User writes with real-time assistance

Drafts auto-save to localStorage every 3 seconds. Word count indicator shows progress toward 220-260 target. Phrase bank provides CAE-level expressions.

AI Evaluation

GPT-4o-mini scores on 4 Cambridge criteria

The AI evaluates using official criteria: Content (task fulfillment), Communicative Achievement (register & tone), Organisation (coherence & cohesion), and Language (grammar & vocabulary).

Model: gpt-4o-mini at temperature 0.3 for consistent, deterministic evaluation
Grade A Rewrite

Optional: Generate an improved version

AI produces a Grade A version of the user's text, preserving their ideas but elevating language. Shown side-by-side in the ComparisonView component for learning.

Track & Improve

Results saved to database

Score, evaluation, and full text saved. Updates the user's progress tracking, feeds into mistake analysis, and adjusts difficulty level for future tasks.

Workflow Detail

Speaking Module — Step by Step

Select Part

User chooses Speaking Part 1-4

Each part mirrors the real CAE exam structure with appropriate time limits: Part 1 (2 min), Part 2 (2 min), Part 3 (3 min), Part 4 (4 min).

Generate Task + Images

AI generates prompt, backend serves exam images

GPT-4o-mini creates the speaking task. For Part 2, image_service.py serves 3 real CAE exam images (user compares 2). Part 3 includes discussion diagrams.

Image Source: 4 sets of 3 images each for Part 2; 8 diagrams for Part 3 — curated from real CAE materials
Prep Time

60-second countdown for Parts 2 & 3

Visual timer counts down. User reviews images/diagrams and prepares response. Timer automatically transitions to recording phase when complete.

Record Audio

Browser records audio using MediaRecorder API

Native browser recording captures audio in WebM format. Live timer shows elapsed time. Auto-stops at the part's time limit.

Tech: navigator.mediaDevices.getUserMedia() → MediaRecorder → Blob upload
Whisper Transcription

Audio uploaded, Whisper converts to text

Audio file uploaded to backend. OpenAI Whisper API transcribes the recording. The transcription becomes the input for AI evaluation.

Pipeline: WebM audio → /api/speaking/submit → Whisper API → Transcription → GPT Evaluation
AI Evaluation

Scored on speaking criteria with detailed feedback

Evaluated on Grammar & Vocabulary, Discourse Management, Pronunciation, and Interactive Communication. Provides specific improvement suggestions.

What Makes It Different

Key Design Decisions

🎛️

Dual Temperature Strategy

Task generation uses temperature 0.8 for creative diversity in prompts. Task evaluation uses temperature 0.3 for consistent, deterministic scoring. This separation ensures varied practice material with reliable grading.

Generate (0.8)
→
Creative Prompts
Evaluate (0.3)
→
Consistent Scores
🎙️

Two-Stage Speaking Pipeline

Audio isn't sent directly to a single model. Instead, Whisper first creates a faithful transcription, then GPT-4o-mini evaluates the text separately. This gives better results than end-to-end audio evaluation.

Audio (WebM)
→
Whisper
→
Transcript
→
GPT Eval
🔄

Feedback Loop Architecture

Submissions feed the Mistake Tracker, which identifies patterns across all attempts. This drives the Targeted Practice system — generating tasks focused specifically on the user's weak areas. Every practice session makes the next one smarter.

📐

Real Exam Simulation

Speaking tasks use real CAE exam images from curated sources. Timing matches actual exam conditions. Part 2 shows 3 images (compare 2), Part 3 includes discussion diagrams — exactly mirroring the exam format students will face.
