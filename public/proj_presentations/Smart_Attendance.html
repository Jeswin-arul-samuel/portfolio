Our Solution

One Camera. Instant Attendance.

A three-step process that replaces manual roll calls with automated face recognition.

🧑‍🎓

1. Register Once

Students register their face via webcam or photo upload. The system extracts and stores a unique 128-dimensional facial encoding.

📷

2. Capture & Recognize

Point a webcam at the class, capture a frame. The system detects all faces and matches them against registered students in real-time.

📊

3. View & Export

Browse attendance records with search and date filters. Download as CSV with a single click for reporting or external use.

Features

What the System Can Do

📝

Student Registration

Register with name, roll number, and face image. Supports both file upload and live webcam capture. Face encoded as a 128-dim vector and stored for future matching.

🎯

Real-Time Face Recognition

Capture a webcam frame and instantly match all detected faces against registered students. Multi-face detection in a single frame. Prevents duplicate marking per day.

🔍

Search & Filter Records

View attendance records in a clean table. Search by student name or roll number. Filter by specific date. Color-coded status indicators — green for Present, red for Absent.

📥

CSV Export

Download attendance data as a date-stamped CSV file (attendance_2024-03-17.csv) for record-keeping, reporting, or integration with other school management systems.

🌐

RESTful API Design

Clean API with proper HTTP methods, JSON request/response, FormData support for file uploads, and Marshmallow schema validation for request data integrity.

📱

Responsive UI

Built with Tailwind CSS for a clean, responsive interface. Intuitive navigation between registration, attendance marking, and record viewing with a centralized home page.

REST API Endpoints

The backend exposes a clean RESTful API consumed by the React frontend.

Roadmap

Future Enhancements

Planned improvements to make the system production-ready and feature-rich.

Phase 1

Authentication & Role-Based Access

Add login system with Admin and Teacher roles. Secure all API endpoints with JWT tokens. Only authorized users can register students or view records.

Phase 2

Dashboard & Analytics

Visual analytics dashboard showing attendance trends, student-wise reports, percentage calculations, and low-attendance alerts with charts and graphs.

Phase 3

Multi-Class & Subject Support

Support for multiple classes, sections, and subjects. Assign students to courses. Track attendance per subject, not just per day.

Phase 4

Liveness Detection

Anti-spoofing measures to prevent attendance fraud using printed photos or screens. Blink detection and head movement verification before marking.

Phase 5

Cloud Deployment & PostgreSQL

Migrate from SQLite to PostgreSQL for production scale. Deploy on AWS/GCP with Docker containers. Environment-based configuration with .env files.

Phase 6

Notifications & Mobile App

Email or SMS alerts for absent students. Push notifications for parents. A companion mobile app for teachers to mark attendance from their phones.
