Imagine you're watching a cricket match 🏏. A fielder runs from deep mid-wicket to point — that's the distance they covered. But the displacement is just the straight line from where they started to where they ended up. What's the difference?
Distance is total path, displacement is start to end?
Exactly! Now here's a tricky one — if the fielder runs to point and then runs back to the same spot, what's the displacement?
Zero?
✅ Perfect! Displacement is zero because the start and end points are the same. The distance, however, is the full path covered. You've grasped this — let's level up to velocity.

Workflow Detail

Student Learning Journey — Step by Step

Onboarding

Student registers and profiles themselves

Chat-based survey collects name, grade, board (CBSE/ICSE/State), interests (cricket, gaming, movies...), and learning preferences. VARK and MSLQ frameworks assess learning style and motivation.

Psychological Profiling: Dweck Growth Mindset assessment, self-efficacy, and motivation scoring run automatically during onboarding.
Diagnostic

Initial knowledge state mapped

The system administers a targeted diagnostic using IRT-calibrated questions to efficiently map what the student already knows. BKT initializes P(Know) per concept.

Algorithm: IRT 3PL model selects maximally informative questions. Fewer questions needed for accurate estimation than traditional tests.
Study Plan

Personalized learning path generated

Knowledge Space Theory (KST) determines which concepts the student is ready to learn based on prerequisite mastery. The system builds an optimal sequence through the curriculum graph.

Learning Session

AI teaches through Socratic dialogue

The LLM tutor uses RAG retrieval from 1,820 vector-stored concept explanations to ground responses. Teaches using the student's interests as context. Real-time WebSocket chat with LaTeX math rendering.

Multi-Agent: Teaching agent, testing agent, review agent, and support agent collaborate via LangGraph orchestrator.
Assessment & Adaptation

Stealth assessments update knowledge state

Questions are woven into conversation naturally. After each response: BKT updates P(Know), Elo adjusts difficulty matching, Bloom's tracks cognitive depth. Misconception detection triggers targeted remediation.

Spaced Review

SM-2 schedules optimal review timing

Mastered concepts enter the spaced repetition scheduler. Review sessions surface at calculated intervals — just before the forgetting curve drops below threshold. Each successful review extends the interval.

Learning Science Engine

9 Algorithms Working in Concert

🧠 Bayesian Knowledge Tracing

Estimates P(Know) per concept. Accounts for guessing, slipping, and learning from each attempt.

P(Know|correct) = P(K)*(1-p_slip) / P(correct)
Knowledge State

📊 Item Response Theory (3PL)

Matches question difficulty to student ability. Maximum information question selection for efficient assessment.

P(correct|θ) = c + (1-c)/(1+exp(-a*(θ-b)))
Adaptive Assessment

🎯 Knowledge Space Theory

Models concept prerequisites as a partial order. Identifies the "outer fringe" — concepts the student is ready to learn next.

Learning Path

⚔️ Elo Rating System

Dynamic difficulty calibration. Both students and questions have Elo ratings that update after each interaction.

R_new = R_old + K * (S - E)
Difficulty Matching

🌿 Bloom's Taxonomy Progression

Tracks cognitive depth: Remember → Understand → Apply → Analyze. Ensures students don't just memorize — they truly understand.

Cognitive Depth

🔄 SM-2 Spaced Repetition

Schedules reviews at optimal intervals based on forgetting curves. Each successful review increases the interval exponentially.

interval = prev_interval * ease_factor
Retention

🔍 Misconception Detection

328 catalogued misconceptions matched to student responses. Detects root misunderstandings, not just wrong answers.

Error Diagnosis

📐 Hake's Normalized Gain

Measures learning effectiveness: g = (post - pre) / (100 - pre). Benchmarks whether the system is actually teaching.

g = (post_score - pre_score) / (max - pre_score)
Effectiveness

🧘 Cognitive Load Monitoring

Tracks response times, error patterns, and engagement signals to estimate mental effort. Prevents overload by adjusting pace.

What Makes It Different

Key Design Decisions

🏏

Interest-Based Contextual Generation

Unlike static content platforms, GLS generates unique explanations for every student-concept pair using their interests. A cricket fan learns projectile motion through ball trajectories. A gamer through in-game physics. This is impossible to pre-author at scale — only GenAI can do it.

Student Interests
→
RAG + Context
→
Personalized Explanation
🎭

Multi-Agent Orchestration

Not a single chatbot. A team of specialized AI agents — teaching, testing, reviewing, and supporting — coordinated by a LangGraph orchestrator. Each agent has its own prompt strategy, tools, and behavioral rules.

Orchestrator
→
Teach
|
Test
|
Review
|
Support
🧬

Stealth Assessment

Questions are woven into natural conversation using Evidence-Centered Design. Students don't feel tested — they feel like they're having a discussion. This reduces test anxiety while capturing authentic understanding signals.

🧠

Holistic Student Modeling

Three-dimensional profiling: Academic (knowledge gaps), Psychological (motivation, mindset), and Learning Style (VARK preferences). The AI adapts not just what to teach, but how to teach each individual.
