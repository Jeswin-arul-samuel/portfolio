Agent Breakdown

The Four AI Agents

Vision

Perception Agent

Salesforce BLIP model processes raw pixel data and generates natural language captions describing the product.

  • Load image via PIL
  • Encode with BLIP processor
  • Generate caption (max 50 tokens)
  • Handle video frame extraction
Model: blip-image-captioning-base
Reasoning

Classification Agent

Takes the BLIP caption and uses GPT-4o to determine product category with structured JSON response.

  • Receive caption string
  • Classify: fashion or electronics
  • Return JSON: {"category": "..."}
  • Fallback to "unknown"
Model: GPT-4o (temperature: 0.7)
Fashion

Fashion Copywriter

Specialized prompt persona that generates fashion-focused e-commerce copy with style-aware language.

  • Catchy product title
  • 40-50 word description
  • 5-6 bullet features
  • Product-only focus (no people)
Persona: Fashion E-Commerce Copywriter
Tech

Electronics Copywriter

Tech-focused prompt persona that generates specification-rich product metadata with technical accuracy.

  • Technical product title
  • 40-50 word description
  • 5-6 spec-focused features
  • BLIP echo detection fallback
Persona: Tech E-Commerce Copywriter

Two-Model Strategy: Why Not Just Use GPT-4 Vision?
Current: BLIP + GPT-4o Pipeline
  • BLIP runs locally — no API cost for captioning
  • GPT-4o receives text only — cheaper API calls
  • Each model handles what it's best at
  • Caption can be cached and reused
Alternative: GPT-4 Vision (Single Model)
  • Image tokens are expensive (~85 tokens per tile)
  • Every request requires image upload to API
  • No local processing — fully API dependent
  • Simpler code but higher operational cost
