Workflow Detail

Customer Journey — Step by Step

Step 1

Welcome & Recognition

AI recognizes returning customer (Tier 3) or greets anonymously (Tier 1). Personalization loaded from profile.

Step 2

Menu Browsing

Hierarchical drill-down: Section (Veg/Non-Veg) → Category (Main Course) → Subcategory (Biryanis) → Items with prices.

Step 3

Smart Discovery

"Something spicy under 300" triggers semantic search. pgvector finds items by meaning, not just keywords. Hybrid: semantic + hierarchy matching.

Step 4

Cart Management

Add by item name, index number, or description. Batch add supported. Price always verified against DB. Post-checkout modifications reset validation.

Step 5

Cart Validation

Live inventory check. Unavailable items flagged. Prices confirmed against current menu.

Step 6

Authentication Flow

Progressive: collect phone → send OTP → verify → lookup/register customer. Existing customers auto-continue without extra steps.

Step 7

Order Creation

Draft order created in DB. Order type (dine-in/takeaway) determines payment flow. Dine-in can pay later (cash).

Step 8

Payment & Confirmation

Razorpay payment link generated. SMS sent. Webhook callback confirms payment. Inventory permanently reserved.

AUTH Auth Node

Frictionless 3-tier recognition. Never blocks the conversation. Identifies returning customers silently.

NLU Perceive

LLM classifies intent + extracts entities. Overrides clarification for agent-handled intents.

CTX Task Manager

Handles context switching. Accumulates entities across turns. LIFO task stack for suspended conversations.

VAL Validation

Entity format checks (phone, quantity, rating). Catches bad data before agents see it.

MAP Router

Maps intent to specialist agent. Auth check before routing. Ensures correct agent handles each request.

OUT Response Agent

Virtual Waiter personality. Hybrid rendering (pre-rendered data + LLM intro/outro). 4-layer anti-hallucination.

What Makes It Different

Key Design Decisions

⚡

20-Account LLM Load Balancer

Round-robin across 20 OpenAI accounts with per-model (gpt-4o vs gpt-4o-mini) rate tracking. Sliding window RPM/TPM. Auto-cooldown at 80% capacity. Zero downtime.

Request → Estimate Tokens → Find Account → Invoke → Record → Cooldown
🛡️

4-Layer Anti-Hallucination

Layer 1: Strict system prompts with grounding rules. Layer 2: Response validation against actual data. Layer 3: Template fallback for failed validation. Layer 4: Dynamic temperature (0.1 for facts, 0.5 for conversation).

Grounding → Validation → Fallback → Temp Control
🧩

Progressive Entity Collection

Agents collect information over multiple turns instead of demanding everything upfront. The perceive node deliberately skips clarification for agent-handled intents. Natural conversation flow.

Turn 1 (item) → Turn 2 (+qty) → Turn 3 (+type) → Ready!
🔄

Task Stack Context Switching

Users can say "actually, book a table" mid-order. The food ordering task gets suspended (pushed to LIFO stack) and automatically resumed later. Multi-tasking without losing context.

Ordering → Suspend → Book Table → Resume Order
